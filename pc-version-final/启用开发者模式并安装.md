# 在没有签名的情况下安装 APPX（开发者模式）

## 问题
APPX 包没有被签名，导致无法安装。错误提示：`0x800B0100: 应用包必须经过数字签名才能进行签名验证。`

## 解决方案：启用开发者模式

### 方法 1：通过设置启用开发者模式

1. 打开 **Windows 设置**
2. 进入 **隐私和安全性** > **开发者选项**（或 **更新和安全** > **开发者选项**）
3. 启用 **开发人员模式**
4. 重启电脑（可选，但建议）

### 方法 2：通过 PowerShell 启用

以管理员权限运行 PowerShell：

```powershell
reg add "HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\AppModelUnlock" /t REG_DWORD /f /v "AllowDevelopmentWithoutDevLicense" /d "1"
```

## 安装步骤

启用开发者模式后，有两种方式安装：

### 方式 1：双击安装

直接双击 `dist\芯图相册-智能分类，便捷管理，仅你可见 1.0.0.appx` 文件

### 方式 2：PowerShell 安装

```powershell
cd d:\ImageClassifierApp\pc-version-final
Add-AppxPackage -Path "dist\芯图相册-智能分类，便捷管理，仅你可见 1.0.0.appx" -ForceApplicationShutdown
```

## 如果仍然失败

### 使用 MakeAppx 解包并重新打包

有时候 electron-builder 生成的 APPX 包存在问题，可以手动重新打包：

1. 安装 Windows SDK（包含 MakeAppx 工具）
   https://developer.microsoft.com/windows/downloads/windows-sdk/

2. 解包 APPX：
```powershell
& "C:\Program Files (x86)\Windows Kits\10\bin\10.0.22621.0\x64\makeappx.exe" unpack /p "dist\芯图相册-智能分类，便捷管理，仅你可见 1.0.0.appx" /d "dist\unpacked"
```

3. 重新打包：
```powershell
& "C:\Program Files (x86)\Windows Kits\10\bin\10.0.22621.0\x64\makeappx.exe" pack /d "dist\unpacked" /p "dist\芯图相册-unsigned.appx"
```

4. 安装未签名的包（需要开发者模式）：
```powershell
Add-AppxPackage -Path "dist\芯图相册-unsigned.appx" -ForceApplicationShutdown
```

## 正式签名（用于分发）

如果要分发给其他用户或提交到 Microsoft Store，必须进行签名：

### 安装 Windows SDK

下载并安装 Windows 10 SDK：
https://developer.microsoft.com/windows/downloads/windows-sdk/

安装时只选择 **Windows App Certification Kit**

### 使用 SignTool 签名

```powershell
$signTool = "C:\Program Files (x86)\Windows Kits\10\bin\10.0.22621.0\x64\signtool.exe"
$appxPath = "dist\芯图相册-智能分类，便捷管理，仅你可见 1.0.0.appx"
$pfxPath = "test-certificate.pfx"
$pfxPassword = "test123456"

& $signTool sign /fd SHA256 /a /f $pfxPath /p $pfxPassword $appxPath
```

### 验证签名

```powershell
& $signTool verify /pa $appxPath
```

## 注意事项

1. **开发者模式仅用于开发测试**
   - 可以安装未签名的应用
   - 不适合普通用户

2. **提交到 Microsoft Store 必须签名**
   - 使用正式的代码签名证书
   - 或使用 Partner Center 提供的证书

3. **旁加载策略**
   - 企业环境可能需要配置组策略
   - 某些企业电脑可能被禁止旁加载

## 卸载应用

如果需要卸载测试应用：

```powershell
Get-AppxPackage *ImageClassifier* | Remove-AppxPackage
```

或通过设置：
设置 > 应用 > 应用和功能 > 找到"芯图相册" > 卸载
