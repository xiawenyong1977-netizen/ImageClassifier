# PC版本构建问题修复说明

## 问题描述

在运行 `npm run build` 时遇到以下错误：

```
TypeError: Cannot read properties of undefined (reading 'indexOf')
at D:\ImageClassifierApp\pc-version-final\node_modules\react-dev-utils\ModuleScopePlugin.js:32:39
```

## 问题原因

`react-dev-utils` 的 `ModuleScopePlugin` 在访问 `request.descriptionFileRoot.indexOf()` 时，`request.descriptionFileRoot` 为 `undefined`，导致构建失败。

## 修复方案

### 方案1：直接修复 ModuleScopePlugin.js（已应用）

修改了 `node_modules/react-dev-utils/ModuleScopePlugin.js` 文件，在访问 `indexOf` 之前添加了 `descriptionFileRoot` 的存在性检查：

```javascript
// 修复前
if (
  request.descriptionFileRoot.indexOf('/node_modules/') !== -1 ||
  request.descriptionFileRoot.indexOf('\\node_modules\\') !== -1 ||
  !request.__innerRequest_request
) {
  return callback();
}

// 修复后
if (
  (request.descriptionFileRoot && request.descriptionFileRoot.indexOf('/node_modules/') !== -1) ||
  (request.descriptionFileRoot && request.descriptionFileRoot.indexOf('\\node_modules\\') !== -1) ||
  !request.__innerRequest_request
) {
  return callback();
}

// 如果 descriptionFileRoot 不存在，跳过检查
if (!request.descriptionFileRoot) {
  return callback();
}
```

### 方案2：使用 patch-package 永久保存修复（推荐）

由于直接修改 `node_modules` 会在重新安装依赖时丢失，建议使用 `patch-package` 来永久保存修复：

#### 安装 patch-package

```bash
npm install --save-dev patch-package
```

#### 在 package.json 中添加 postinstall 脚本

```json
{
  "scripts": {
    "postinstall": "patch-package"
  }
}
```

#### 生成 patch 文件

```bash
npx patch-package react-dev-utils
```

这会在 `patches/` 目录下生成一个 patch 文件，每次 `npm install` 后会自动应用修复。

## 构建结果

修复后构建成功，虽然有一些 source map 警告，但不影响构建结果：

## 注意事项

1. **source map 警告**：`onnxruntime-react-native` 的 source map 文件缺失，这是警告不是错误，不影响构建
2. **重新安装依赖**：如果重新运行 `npm install`，需要重新应用修复或使用 `patch-package`
3. **版本兼容性**：此修复适用于 `react-dev-utils@12.0.1` 和 `react-scripts@5.0.1`
