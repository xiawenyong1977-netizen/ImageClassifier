# 鸿蒙开发环境安装指南

## 📋 环境要求

### 系统要求
- **操作系统**：Windows 10/11 (64位)
- **内存**：8GB 以上（推荐 16GB）
- **磁盘空间**：至少 10GB 可用空间

### 软件要求
- **Node.js**：v16.0.0 或更高版本 ✅ (当前: v20.19.4)
- **npm**：v8.0.0 或更高版本 ✅ (当前: 10.8.2)
- **Java JDK**：OpenJDK 17 或更高版本 ⚠️ (需要安装)
- **DevEco Studio**：最新版本 ⚠️ (需要安装)

---

## 一、安装步骤

### 步骤1：安装 Java JDK

#### 1.1 下载 OpenJDK 17

访问以下任一网站下载：
- **华为镜像**：https://mirrors.huaweicloud.com/java/jdk/17.0.2+8/
- **Adoptium**：https://adoptium.net/zh-CN/temurin/releases/?version=17
- **Oracle**：https://www.oracle.com/java/technologies/downloads/#java17

#### 1.2 安装 JDK

1. 运行安装程序
2. 选择安装路径（建议：`C:\Program Files\Java\jdk-17`）
3. 完成安装

#### 1.3 配置环境变量

1. 右键"此电脑" → "属性" → "高级系统设置" → "环境变量"
2. 在"系统变量"中新建：
   - **变量名**：`JAVA_HOME`
   - **变量值**：`C:\Program Files\Java\jdk-17`（你的JDK安装路径）
3. 编辑"Path"变量，添加：
   - `%JAVA_HOME%\bin`
4. 验证安装：
   ```bash
   java -version
   javac -version
   ```

---

### 步骤2：安装 DevEco Studio

#### 2.1 下载 DevEco Studio

访问华为开发者官网：
- **官网**：https://developer.harmonyos.com/cn/develop/deveco-studio
- **下载页面**：https://developer.harmonyos.com/cn/develop/deveco-studio#download

选择 Windows 版本下载（.exe 安装包）

#### 2.2 安装 DevEco Studio

1. 运行安装程序
2. 选择安装路径（建议：`C:\Program Files\Huawei\DevEco Studio`）
3. 选择组件：
   - ✅ DevEco Studio
   - ✅ HarmonyOS SDK
   - ✅ Node.js（如果未安装）
4. 完成安装

#### 2.3 首次启动配置

1. 启动 DevEco Studio
2. 选择"Standard"安装类型
3. 接受许可协议
4. 等待 SDK 下载完成（可能需要较长时间）
5. 创建或登录华为开发者账号

---

### 步骤3：安装 ohpm（鸿蒙包管理器）

#### 3.1 通过 DevEco Studio 安装（推荐）

ohpm 通常随 DevEco Studio 一起安装，位于：
```
C:\Users\<用户名>\AppData\Local\Huawei\ohpm\bin\ohpm.exe
```

#### 3.2 手动安装 ohpm

如果未自动安装，可以：

1. **通过 npm 安装**（如果支持）：
   ```bash
   npm install -g @ohos/ohpm
   ```

2. **或下载独立安装包**：
   - 访问：https://ohpm.openharmony.cn/
   - 下载 Windows 版本
   - 解压到指定目录
   - 添加到 PATH 环境变量

#### 3.3 验证安装

```bash
ohpm --version
```

---

### 步骤4：配置环境变量

将以下路径添加到系统 PATH：

1. **ohpm**（如果未自动添加）：
   ```
   C:\Users\<用户名>\AppData\Local\Huawei\ohpm\bin
   ```

2. **DevEco Studio**（可选）：
   ```
   C:\Program Files\Huawei\DevEco Studio\bin
   ```

## 三、配置 ohpm 镜像源（可选，加速下载）

### 3.1 使用华为镜像源

```bash

```

### 3.2 验证配置

```bash
ohpm config get registry
```

## 四、常见问题

### Q1: Java 未找到

**解决方案**：
1. 确认已安装 JDK 17 或更高版本
2. 检查 JAVA_HOME 环境变量是否正确
3. 重启命令行窗口或重启电脑

### Q2: ohpm 命令未找到

**解决方案**：
1. 检查 ohpm 是否已安装
2. 将 ohpm 路径添加到 PATH 环境变量
3. 重启命令行窗口

### Q3: SDK 下载失败

**解决方案**：
1. 检查网络连接
2. 使用 VPN 或代理（如果需要）
3. 手动下载 SDK 并配置路径

### Q4: DevEco Studio 启动慢

**解决方案**：
1. 增加内存分配（Help → Edit Custom VM Options）
2. 关闭不必要的插件
3. 使用 SSD 硬盘
