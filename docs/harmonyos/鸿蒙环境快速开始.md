## 🚀 快速开始步骤

### 步骤1：设置 JAVA_HOME（可选但推荐）

1. 找到 Java 安装路径（通常在 `C:\Program Files\Java\jdk-17`）
2. 设置环境变量：
   ```powershell
   # PowerShell (管理员)
   [System.Environment]::SetEnvironmentVariable("JAVA_HOME", "C:\Program Files\Java\jdk-17", "Machine")
   ```
3. 或手动设置：
   - 右键"此电脑" → "属性" → "高级系统设置" → "环境变量"
   - 新建系统变量：`JAVA_HOME` = `C:\Program Files\Java\jdk-17`
   - 编辑 `Path`，添加：`%JAVA_HOME%\bin`

### 步骤2：安装 DevEco Studio 和 ohpm

#### 方法A：安装 DevEco Studio（推荐）

1. **下载 DevEco Studio**
   - 访问：https://developer.harmonyos.com/cn/develop/deveco-studio#download
   - 下载 Windows 版本

2. **安装 DevEco Studio**
   - 运行安装程序
   - 选择安装路径
   - 确保勾选 "HarmonyOS SDK" 和 "Node.js"（如果未安装）
   - 完成安装

3. **ohpm 会自动安装**
   - ohpm 通常随 DevEco Studio 一起安装
   - 路径：`C:\Users\<用户名>\AppData\Local\Huawei\ohpm\bin\ohpm.exe`

4. **添加到 PATH**
   - 将 ohpm 路径添加到系统 PATH 环境变量
   - 或使用完整路径运行

#### 方法B：手动安装 ohpm（如果不想安装 DevEco Studio）

1. 访问：https://ohpm.openharmony.cn/
2. 下载 Windows 版本
3. 解压到指定目录
4. 添加到 PATH 环境变量

### 步骤3：配置 ohpm 镜像源（加速下载）

```bash
ohpm config set registry https://repo.harmonyos.com/ohpm/
```

验证配置：
```bash
ohpm config get registry
```

### 步骤4：验证环境

运行环境检查：
```bash
npm run harmonyos:check
```

应该看到所有检查项都通过 ✅

### 步骤5：初始化鸿蒙项目

```bash
npm run harmonyos:init
```

这将创建 `harmonyos/` 目录和基本项目结构。

### 步骤6：测试依赖包下载

```bash
npm run harmonyos:test-deps
```

这将测试所有支持的库是否可以正确下载。

### 步骤7：安装依赖

```bash
npm run harmonyos:install
```

这将安装所有在 `oh-package.json5` 中配置的依赖包。

## 🔧 故障排除

### 问题1：ohpm 命令未找到

**解决方案**：
1. 确认 ohpm 已安装
2. 找到 ohpm.exe 的路径
3. 添加到 PATH 环境变量
4. 重启命令行窗口

### 问题2：依赖包下载失败

**解决方案**：
1. 检查网络连接
2. 配置镜像源：`ohpm config set registry https://repo.harmonyos.com/ohpm/`
3. 使用 VPN 或代理（如果需要）

### 问题3：JAVA_HOME 未设置

**解决方案**：
- 虽然 Java 可以运行，但设置 JAVA_HOME 有助于某些工具正常工作
- 参考步骤1设置 JAVA_HOME
