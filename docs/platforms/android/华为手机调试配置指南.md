# 华为手机作为Android调试设备配置指南

## 📱 第一步：开启开发者模式

### 1.1 进入关于手机
```
设置 → 关于手机
或
设置 → 系统 → 关于手机
```

### 1.2 连续点击版本号
- 找到 **"版本号"** 或 **"Build号"**
- **连续快速点击 7 次**
- 提示：**"您已处于开发者模式"**

---

## 🔧 第二步：开启USB调试

### 2.1 进入开发人员选项
```
设置 → 系统和更新 → 开发人员选项
或
设置 → 系统 → 开发人员选项
```

### 2.2 必须开启的选项
- ✅ **开发人员选项** - 主开关
- ✅ **USB调试** - 允许ADB连接
- ✅ **"仅充电"模式下允许ADB调试** - 避免模式切换问题
- ✅ **USB安装** - 允许通过USB安装应用

### 2.3 推荐开启的选项
- ✅ **不锁定屏幕** - 调试时保持屏幕常亮
- ✅ **通过USB验证应用** - 安全检查

---

## 🔌 第三步：连接电脑

### 3.1 使用USB数据线连接
- 使用**原装数据线**或**质量好的数据线**
- 插入电脑的 **USB 3.0** 接口（蓝色接口，速度更快）

### 3.2 手机上会弹出提示
```
允许USB调试吗？
计算机的RSA密钥指纹：
xxxxxxxxxxxxxxxx

[ ] 一律允许使用这台计算机进行调试

[取消] [确定]
```

**操作**：
1. ✅ **勾选"一律允许使用这台计算机进行调试"**
2. 点击 **"确定"**

### 3.3 选择USB连接模式
如果手机弹出USB连接模式选择：
- 选择 **"传输文件"** 或 **"MTP"** 模式
- 或者选择 **"仅充电"**（如果已开启"仅充电模式下允许ADB调试"）

---

## 🖥️ 第四步：在电脑上验证连接（Windows）

### 4.1 打开PowerShell或命令提示符
```powershell
# 方法1：Win + R，输入 powershell，回车
# 方法2：在项目文件夹按住 Shift + 右键，选择"在此处打开PowerShell窗口"
```

### 4.2 检查ADB连接
```powershell
cd D:\ImageClassifierApp\android
.\gradlew --version

# 检查连接的设备
adb devices
```

**期望输出**：
```
List of devices attached
ABC123456789    device
```

如果显示：
- `ABC123456789    device` ✅ - 连接成功
- `ABC123456789    unauthorized` ❌ - 未授权，检查手机上的授权弹窗
- `ABC123456789    offline` ❌ - 离线，重新插拔USB
- 空列表 ❌ - 未识别，需要安装驱动

---

## 🔧 第五步：安装华为手机驱动（如果需要）

### 5.1 检查是否需要安装驱动
如果 `adb devices` 显示为空或显示"未识别的设备"：

### 5.2 方法1：使用HiSuite（推荐）
1. 访问华为官网：https://consumer.huawei.com/cn/support/hisuite/
2. 下载并安装 **HiSuite（华为手机助手）**
3. 连接手机，HiSuite会自动安装驱动
4. 安装完成后，关闭HiSuite（不影响ADB调试）

### 5.3 方法2：手动安装驱动
1. 打开 **设备管理器**（Win + X → 设备管理器）
2. 找到带有黄色感叹号的 **Android设备** 或 **便携设备**
3. 右键 → **更新驱动程序**
4. 选择 **"浏览我的计算机以查找驱动程序"**
5. 选择 **"让我从计算机上的可用驱动程序列表中选取"**
6. 选择 **"Android ADB Interface"** 或 **"MTP USB设备"**

---

## 🚀 第六步：运行React Native应用

### 6.1 确认设备已连接
```powershell
cd D:\ImageClassifierApp
adb devices
```

### 6.2 运行应用
```powershell
# 启动Metro服务器
npm start

# 在新的PowerShell窗口运行
npx react-native run-android
```

### 6.3 或者构建并安装
```powershell
cd android
.\gradlew assembleDebug

# 安装到手机
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

## 🐛 常见问题排查

### 问题1：adb devices显示unauthorized
**原因**：未在手机上授权

**解决**：
```powershell
# 撤销所有USB调试授权
adb kill-server
adb start-server
adb devices
```
然后在手机上重新授权

---

### 问题2：adb devices显示offline
**原因**：连接不稳定

**解决**：
1. 重新插拔USB线
2. 换一个USB接口
3. 换一根数据线
4. 重启ADB服务：
   ```powershell
   adb kill-server
   adb start-server
   ```

---

### 问题3：adb devices显示空列表
**原因**：驱动未安装或USB调试未开启

**解决**：
1. 确认手机上USB调试已开启
2. 确认已授权此电脑
3. 安装华为手机驱动（使用HiSuite）
4. 检查USB线是否支持数据传输

---

### 问题4：连接成功但应用无法安装
**原因**：安装权限或签名问题

**解决**：
1. 开启"USB安装"选项
2. 关闭"通过USB验证应用"
3. 卸载旧版本应用：
   ```powershell
   adb uninstall com.imageclassifier
   ```
4. 重新安装

---

### 问题5：华为手机特有问题 - 安装失败
**原因**：华为安全策略

**解决**：
1. **关闭纯净模式**：
   ```
   设置 → 系统和更新 → 纯净模式 → 关闭
   ```

2. **允许从USB安装**：
   ```
   设置 → 安全 → 更多安全设置 → 安装外部来源应用 → 允许
   ```

3. **关闭应用分身**（如果有）

---

## ⚡ 快速命令参考

### 基本命令
```powershell
# 列出设备
adb devices

# 查看设备信息
adb shell getprop ro.product.model
adb shell getprop ro.build.version.release

# 安装APK
adb install -r path/to/app.apk

# 卸载应用
adb uninstall com.imageclassifier

# 查看日志
adb logcat | grep "ReactNative"

# 重启ADB
adb kill-server
adb start-server
```

### 调试命令
```powershell
# 清除应用数据
adb shell pm clear com.imageclassifier

# 启动应用
adb shell am start -n com.imageclassifier/.MainActivity

# 截图
adb shell screencap /sdcard/screenshot.png
adb pull /sdcard/screenshot.png

# 录屏
adb shell screenrecord /sdcard/demo.mp4
adb pull /sdcard/demo.mp4
```

- [ ] 手机已开启开发者模式
- [ ] USB调试已开启
- [ ] "仅充电模式下允许ADB调试"已开启

## 🎯 华为手机特别注意事项

### 1. 纯净模式
华为手机的"纯净模式"可能阻止安装未知来源应用，建议关闭。

### 2. 应用市场验证
如果安装失败，尝试：
```
设置 → 应用和服务 → 应用市场 → 设置 → 关闭"安装时检查"
```

### 3. 电池优化
调试时建议关闭应用的电池优化：
```
设置 → 电池 → 应用启动管理 → 找到你的应用 → 手动管理 → 全部允许
```

### 4. 权限管理
华为手机权限管理较严格，首次运行时注意授予所需权限。

## 🚀 后续开发

代码修改后：
1. 保存文件
2. 在手机上按 **R R**（快速按两次R键）重新加载

```powershell
adb shell input keyevent 82
```

```powershell
# 方法1：Metro控制台自动显示
npm start

# 方法2：直接查看React Native日志
adb logcat | grep "ReactNative"

adb logcat
```
