## 🔧 移动端配置步骤

### Android配置

```bash
# 1. 安装依赖
npm install onnxruntime-react-native react-native-canvas

# 2. 创建assets目录
mkdir -p android/app/src/main/assets/models

# 3. 复制模型文件
cp public/models/yolov8s.onnx android/app/src/main/assets/models/
cp public/models/mobilenetv3_rw_Opset17.onnx android/app/src/main/assets/models/
cp public/models/id_card_detection.onnx android/app/src/main/assets/models/

# 4. 清理重新构建
cd android && ./gradlew clean && cd ..

# 5. 运行测试
npm run android
```

### iOS配置

```bash
# 1. 安装依赖
npm install onnxruntime-react-native react-native-canvas

# 2. 在Xcode中添加模型文件
# - 打开 ios/ImageClassifierApp.xcworkspace
# - 右键项目 -> Add Files to "ImageClassifierApp"
# - 选择 public/models/ 目录下的所有.onnx文件
# - 勾选 "Copy items if needed"
# - 勾选 "Create folder references"

# 3. 安装Pod依赖
cd ios && pod install && cd ..

# 4. 运行测试
npm run ios
```

## ✅ 关键决策记录

### 1. **保持PC端逻辑不变**
- ✅ PC端已经过充分测试
- ✅ 降低回归风险
- ✅ 减少工作量

### 2. **使用相同技术栈**
- ✅ 使用 `onnxruntime-react-native`（而非纯远程API）
- ✅ 使用 `react-native-canvas`（而非平台分叉）
- ✅ 保持降级方案（远程→本地）

### 3. **接受性能差异**
- ✅ 移动端哈希计算单线程（而非开发原生多线程）
- ✅ 移动端推理较慢（而非只用远程API）
- ✅ 优先保证功能一致性

### 4. **最小化改动**
- ✅ 不添加不必要的适配器（FileOperationAdapter）
- ✅ 只增强必要的功能（Android MediaStore）
- ✅ 保持现有API不变
