# 图片预览动态刷新功能说明

## 📋 功能概述

在图片预览页面（`ImagePreviewScreen.mobile.js`）中，当用户暂存照片（标记为待处置）或修改照片分类后，自动重新加载图片列表并更新显示，让用户可以自然地浏览下一张照片。

---

## 🎯 功能需求

### 用户场景

用户在浏览某个分类（如"风景"）的照片时：
1. **当前状态**：第 3 张，共 10 张
2. **操作**：将第 3 张标记为"待处置"或改为"人物"分类
3. **期望结果**：
   - 该照片从当前分类中移除
   - 自动显示下一张（原来的第 4 张）
   - 标题更新为：第 3 张，共 9 张
   - 用户继续浏览，无需返回列表

---

## 🔧 技术实现

### 1. 状态管理升级

**修改前**：
```javascript
const { allImages = [] } = route.params || {};
// allImages 是不可变的路由参数
```

**修改后**：
```javascript
const { allImages = [] } = route.params || {};
const [allImagesState, setAllImagesState] = useState(allImages);
// 使用 state 管理图片列表，支持动态更新
```

---

### 2. 重新加载函数

新增 `reloadImageList()` 函数，根据不同来源重新加载数据：

```javascript
const reloadImageList = async () => {
  try {
    let updatedImages = [];
    
    // 1. 相似组
    if (similarityGroupId) {
      const groupData = await UnifiedDataService.getSimilarityGroupImages(similarityGroupId);
      updatedImages = groupData.images || [];
    }
    
    // 2. 城市分类
    else if (city) {
      const allImages = await UnifiedDataService.readAllImages();
      updatedImages = allImages.filter(img => img.city === city);
    }
    
    // 3. 普通分类
    else if (category) {
      updatedImages = await UnifiedDataService.readImagesByCategory(category);
    }
    
    // 更新图片列表
    setAllImagesState(updatedImages);
    
    // 调整当前索引（如果超出范围）
    if (currentImageIndex >= updatedImages.length) {
      const newIndex = updatedImages.length - 1;
      setCurrentImageIndex(newIndex);
      flatListRef.current?.scrollToIndex({ index: newIndex, animated: true });
    }
    
    return true;
  } catch (error) {
    logger.error('重新加载失败:', error);
    return false;
  }
};
```

---

### 3. 暂存操作集成

在 `handleDelete()` 中，标记为待处置后调用重新加载：

```javascript
const handleDelete = () => {
  Alert.alert(
    '标记为待处置',
    '确定要将这张图片标记为待处置吗？',
    [
      { text: '取消', style: 'cancel' },
      {
        text: '标记',
        onPress: async () => {
          // 1. 更新分类
          await UnifiedDataService.updateImageCategory(
            currentImage.id, 
            'tobecleaned', 
            'manual'
          );
          
          // 2. 重新加载图片列表 ✅
          const reloaded = await reloadImageList();
          if (reloaded) {
            Alert.alert('操作完成', '图片已标记为待处置');
          }
        }
      }
    ]
  );
};
```

---

### 4. 分类修改集成

在 `handleCategoryChange()` 中，修改分类后调用重新加载：

```javascript
const handleCategoryChange = async (newCategory) => {
  // 1. 更新分类
  await UnifiedDataService.updateImageCategory(
    currentImage.id, 
    newCategory, 
    'manual'
  );
  
  // 2. 更新本地状态
  setCurrentImage(prev => ({ 
    ...prev, 
    category: newCategory,
    confidence: 'manual'
  }));
  
  // 3. 重新加载图片列表（如果从分类页进入） ✅
  if (category && category !== newCategory) {
    await reloadImageList();
  }
};
```

## 🔍 边界处理

### 1. 删除最后一张

```javascript
if (currentImageIndex >= updatedImages.length) {
  // 调整到新的最后一张
  const newIndex = updatedImages.length - 1;
  setCurrentImageIndex(newIndex);
  flatListRef.current?.scrollToIndex({ index: newIndex, animated: true });
}
```

**用户看到**：
- 删除前：第 10 张，共 10 张
- 删除后：第 9 张，共 9 张（自动跳到新的最后一张）

---

### 2. 删除唯一一张

```javascript
if (updatedImages.length === 0) {
  Alert.alert('提示', '当前分类已无图片', [
    { text: '确定', onPress: goBack }
  ]);
  return false;
}
```

**用户看到**：
- 删除前：第 1 张，共 1 张
- 删除后：提示"当前分类已无图片"，自动返回列表页

---

### 3. 不同来源的处理

| 来源 | 重新加载方式 |
|------|-------------|
| **分类页** | `UnifiedDataService.readImagesByCategory(category)` |
| **城市页** | 过滤 `readAllImages()` 中的 `city` 字段 |
| **相似组** | `UnifiedDataService.getSimilarityGroupImages(groupId)` |
