## 🚀 安装步骤

### 步骤1：设置 JAVA_HOME（可选但推荐）

#### 方法A：手动设置（推荐）

1. 右键"此电脑" → "属性" → "高级系统设置" → "环境变量"
2. 在"系统变量"中点击"新建"：
   - **变量名**：`JAVA_HOME`
   - **变量值**：`C:\Program Files\Common Files\Oracle\Java`
3. 点击"确定"保存
4. 重启命令行窗口

#### 方法B：使用 PowerShell（需要管理员权限）

```powershell
# 以管理员身份运行 PowerShell
[Environment]::SetEnvironmentVariable("JAVA_HOME", "C:\Program Files\Common Files\Oracle\Java", "Machine")
```

验证设置：
```bash
echo %JAVA_HOME%
# 应该显示: C:\Program Files\Common Files\Oracle\Java
```

---

### 步骤2：安装 DevEco Studio 和 ohpm

#### 2.1 下载 DevEco Studio

1. **访问下载页面**：
   - 官网：https://developer.harmonyos.com/cn/develop/deveco-studio#download
   - 或直接打开：https://developer.harmonyos.com/cn/develop/deveco-studio

2. **下载 Windows 版本**
   - 选择 `.exe` 安装包
   - 文件大小约 1-2GB

#### 2.2 安装 DevEco Studio

1. **运行安装程序**
   - 双击下载的 `.exe` 文件

2. **选择安装路径**
   - 建议：`C:\Program Files\Huawei\DevEco Studio`
   - 或自定义路径

3. **选择组件**
   - ✅ DevEco Studio
   - ✅ HarmonyOS SDK（重要！）
   - ✅ Node.js（如果未安装）

4. **完成安装**
   - 等待安装完成（可能需要较长时间）
   - SDK 下载可能需要额外时间

#### 2.3 首次启动配置

1. **启动 DevEco Studio**
   - 从开始菜单或桌面快捷方式启动

2. **选择安装类型**
   - 选择 "Standard"（标准安装）

3. **接受许可协议**
   - 阅读并接受许可协议

4. **等待 SDK 下载**
   - 首次启动会自动下载 HarmonyOS SDK
   - 这可能需要较长时间（取决于网络速度）
   - 建议保持网络连接稳定

5. **登录/注册华为开发者账号**
   - 如果没有账号，需要先注册
   - 访问：https://developer.huawei.com/

#### 2.4 ohpm 自动安装

- ohpm 会随 DevEco Studio 一起安装
- 通常位于：`C:\Users\<用户名>\AppData\Local\Huawei\ohpm\bin\ohpm.exe`

---

### 步骤3：配置 ohpm 环境变量

#### 3.1 找到 ohpm 路径

ohpm 通常安装在：
```
C:\Users\<你的用户名>\AppData\Local\Huawei\ohpm\bin
```

#### 3.2 添加到 PATH

1. **方法A：手动添加**
   - 右键"此电脑" → "属性" → "高级系统设置" → "环境变量"
   - 编辑"系统变量"中的 `Path`
   - 点击"新建"，添加 ohpm 的 bin 目录路径
   - 点击"确定"保存

2. **方法B：使用 PowerShell（需要管理员权限）**
   ```powershell
   $ohpmPath = "$env:LOCALAPPDATA\Huawei\ohpm\bin"
   $currentPath = [Environment]::GetEnvironmentVariable("Path", "Machine")
   [Environment]::SetEnvironmentVariable("Path", "$currentPath;$ohpmPath", "Machine")
   ```

#### 3.3 验证安装

重启命令行窗口后，运行：
```bash
ohpm --version
```

应该显示版本号，例如：`1.0.0` 或类似版本。

---

### 步骤4：配置 ohpm 镜像源（加速下载）

```bash
ohpm config set registry https://repo.harmonyos.com/ohpm/
```

验证配置：
```bash
ohpm config get registry
```

应该显示：`https://repo.harmonyos.com/ohpm/`

---

### 步骤5：验证环境

运行环境检查：
```bash
npm run harmonyos:check
```

所有检查项应该都显示 ✅

---

### 步骤6：测试依赖包下载

```bash
npm run harmonyos:test-deps
```

这将测试所有支持的库是否可以正确下载。

---

### 步骤7：安装依赖

```bash
npm run harmonyos:install
```

这将安装所有在 `oh-package.json5` 中配置的依赖包。

## ⚠️ 注意事项

1. **安装时间**：
   - DevEco Studio 安装：约 10-30 分钟
   - SDK 下载：约 30-60 分钟（取决于网络速度）
   - 总时间：约 1-2 小时

2. **磁盘空间**：
   - DevEco Studio：约 2-3GB
   - HarmonyOS SDK：约 5-10GB
   - 建议至少 15GB 可用空间

3. **网络要求**：
   - 需要稳定的网络连接
   - 建议使用国内网络或配置代理

4. **权限要求**：
   - 某些操作需要管理员权限
   - 建议以管理员身份运行安装程序
