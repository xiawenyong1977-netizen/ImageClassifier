📊 数据表结构

相似度数据表设计： { "imageId1": { "similarity_features": {...}, // 颜色直方图特征 "similarity_group_id": "group_1", // 相似组ID "similarity_group_type": "duplicate", // 组类型 "similarity_score": 0.95, // 相似度分数 "is_similarity_processed": true, // 是否已处理 "updatedAt": "2024-01-15T10:30:00Z" // 更新时间 }, "imageId2": {...} } 优势： ✅ 性能优化 - 相似度检测不需要加载完整图片数据 ✅ 存储效率 - 避免在主表中存储大量特征数据 ✅ 功能解耦 - 相似度功能独立，不影响主功能 ✅ 扩展性好 - 可以独立优化相似度算法
